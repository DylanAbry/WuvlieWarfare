# WuvlieWarfare
A VR arcade shooter game that can be played only on the Meta Quest 3. Battle against the four members of the Wuvlie family, Pinchypup, Hoppo, Shellshark, and Rattlemeowser to achieve as high of a score as possible. Collect sweet treats, open mystery chests, and unlock new maps to explore in this fun VR experience!

NOTE: This repository contains only the C# scripts for the game, and does not include any assets used in the project.
